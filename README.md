# 任務計時器 PWA

## __這是大部分由AI輔助製作的測試專案，不做任何用途__

## 功能
- 設定總時間、每項顯示時間、難度、字詞與任務
- 開始、暫停／繼續、下一項、手動結束
- 本機建立素材集並匯入圖片／影片
- 隨機或依序切換文字及素材
- 儲存多組預設、查看及匯出執行紀錄
- PWA 離線快取（首次開啟需要載入一次）

## 啟動（需要透過 localhost 或 HTTPS，不要直接點開 index.html）
### 電腦
1. 解壓縮本專案。
2. 安裝 Python 3（若尚未安裝）。
3. 在專案資料夾開啟終端機，執行：
   `python -m http.server 8000`
4. 在同一台電腦瀏覽器開啟 `http://localhost:8000`。

### 手機測試
手機與電腦連同一個 Wi-Fi，先在電腦執行伺服器，再查電腦的區域網路 IP（例如 192.168.1.20），手機瀏覽器開啟 `http://192.168.1.20:8000`。部分瀏覽器只會在 localhost/HTTPS 啟用 PWA 及 Service Worker，因此最可靠的安裝方式是部署到 HTTPS 靜態主機（例如 GitHub Pages、Cloudflare Pages），或使用支援 HTTPS 的本機開發工具。

## 使用
1. 在「設定」輸入預設名稱、難度、總時間、每項秒數。
2. 每行輸入一個字詞、一個任務；留空也能執行。
3. 在「素材庫」建立素材集，再用「選擇圖片／影片」匯入檔案；如果設定頁選中了素材集，匯入會加入該集。
4. 回到「設定」選擇素材集、依序或隨機播放，按「套用設定」。
5. 按「儲存為預設」可儲存多組設定。
6. 到「執行」按「開始」。項目會依每項顯示時間自動切換，也可按「下一項」手動切換。
7. 「紀錄」可查看過往執行並匯出 JSON。

## 資料與限制
- 設定及紀錄儲存在瀏覽器 localStorage；媒體檔案儲存在 IndexedDB，僅限此瀏覽器／此裝置。
- 清除網站資料或瀏覽器儲存可能刪除內容。請備份原始媒體。
- 大型影片可能超出瀏覽器配額。第一版不會把素材上傳到雲端，也不會跨裝置同步。
- 背景／鎖屏時瀏覽器可能限制計時器；請保持頁面開啟。第一版的計時精度適合一般個人用途，不適用於需要嚴格精準的場景。
- 目前每次切換使用相同索引輪替字詞、任務與素材；隨機模式主要影響素材的抽取，下一版可再擴充成文字與任務獨立隨機。
